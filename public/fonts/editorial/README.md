# Original APAR editorial typography

Archivo is the original body and navigation family (normal, weights 300–900).
Newsreader is the original display family (normal and italic, weights 400–500,
optical sizes 6–72). Latin and extended Latin subsets are served locally so
rendering does not require a third-party stylesheet or font request.

These unmodified WOFF2 files come from Google Fonts:

- https://fonts.google.com/specimen/Archivo
- https://fonts.google.com/specimen/Newsreader

Both families use the SIL Open Font License; their original license notices
are included in `archivo-OFL.txt` and `newsreader-OFL.txt`.

The existing APAR Fit logo fonts are independent and unchanged.
