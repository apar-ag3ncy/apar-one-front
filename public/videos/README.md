# Project videos (home "Selected work" gallery)

Drop a video here named by the client's case **slug**, e.g.:

- `chheda.mp4`, `girvaan.mp4`, `diarah.mp4`, `maison-mireyaa.mp4`, `achal.mp4`,
  `high-on-smiles.mp4`, `silver-emporium.mp4`, `a-paramount.mp4`,
  `kundan-jewellers.mp4`, `jatubhai-velji.mp4`, `signi.mp4`, `tarava.mp4`

The matching card in the home "Selected work" horizontal gallery will autoplay
it (muted, looping). Until a file exists, the card shows a "Drop … video"
placeholder. No code change needed — just add the file.

Tips: use **.mp4 (H.264)**, muted, and keep them reasonably small/compressed
(autoplay requires muted). 16:9-ish or portrait both work — they're cropped to fill.
